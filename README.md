## How it works

`main.py` writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), enforcing the gate: UTF-8 text, 1–200 characters, a single line, no surrounding whitespace.

```sh
python3 main.py
```
